This workshop requires participants to have access to a computer - either laptop or desktop which has graphical file viewer software. This is available by default on Windows, MacOS and most flavours of linux.

If you do not have access to a computer and are attending an in person version of the workshop please check with your instructors running the course so they can find a workable solution. This course may be run in a computer cluster room so long as all participants have login access to the cluster room computers. 


## Data Sets

Our example dataset consists of a number of files based around the the lives of penguins, and/or images built off these lessons. These exist as examples of what not to do and/or examples which can be proved. 

We have produced an example dataset for a project on penguins. This makes use of the [palmer penguins dataset][git_palpen] by Allison Horst, Alison Hill and Kristen Gorman and other data generated for this project. This is possible because palmer penguins uses a CC0 1.0 Universal license. But these data have been altered to be representative of a badly maintained dataset for the purposes of these lessons. 

Source: [inst/CITATION][git_pencite]

```quote 
Horst AM, Hill AP, Gorman KB (2020). 
palmerpenguins: Palmer Archipelago (Antarctica) penguin data. 
R package version 0.1.0. 
https://allisonhorst.github.io/palmerpenguins/. 
doi: 10.5281/zenodo.3960218.
```

These data and files are contained in the folder called ```penguin_project_data``` and represent a badly maintained project which you have been given at the start of a project. These files will be used as the basis for various exercises throughout the lessons.

The lesson on tabular data will have its own example data, independent of the penguin dataset, which it is more tailored for the exercises in that lesson. 


::::::::::::::::: callout

During discussions in the following lessons consider your own projects and the data management needs you foresee. As we go through the lessons try and apply them to your own work, either currently or consider how you might have improved your previous work.  

::::::::::::::::::

Download the [data zip file](episodes/data/data.zip) and unzip it to your Desktop.
If you have difficulties doing this please ask your instructor for help.
